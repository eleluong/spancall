# Historical Archive (Lean v2.x – v3.2)

This directory holds superseded notebooks, notebook builders, historical design/experiment plans, and notebook-builder tests from Lean v2.0 through v3.2.

Active v3.3+ assets live in the top-level directories:
- `notebooks/` — `spancall_lean_v3_3_train_eval.ipynb`, `spancall_tau_bench_agentic_eval.ipynb`
- `scripts/` — v3.3 data/train/eval/export CLIs and agentic runners
- `plans/` — `lean_v3_3_plan.md`, `agent_tau_bench_plan.md`
- `tests/` — active library, pipeline, model, and agentic test suite
