\section{Related Work}

\paragraph{Autoregressive function calling and compact tool-use models.}
Tool-augmented LLMs \citep{schick2023toolformer,yao2023react,patil2023gorilla,qin2024toolllm} frame API invocation as causal sequence generation, supported by synthetic data pipelines and benchmarks including Hermes V1 \citep{teknium2024hermes}, APIGen and xLAM \citep{liu2024apigen,zhang2024xlam}, ToolACE \citep{liu2025toolace}, BFCL \citep{yan2024bfcl}, and $\tau$-bench \citep{yao2025taubench}. To lower serving cost and improve generalization to unseen APIs, smaller specialized LLMs combine tool retrieval, quantization, or function-name masking---such as TinyAgent \citep{erdogan2024tinyagent}, Hammer \citep{lin2025hammer}, and xLAM \citep{zhang2024xlam}---while SimpleTool \citep{shi2026simpletool} compresses low-entropy JSON delimiters and decodes argument sub-sequences in parallel. All of these systems remain within the autoregressive generative paradigm and can still fabricate argument values. \textsc{SpanCall} makes a narrower, orthogonal bet: for groundable calls (\textbf{Stratum~F}), it replaces token generation with a single non-autoregressive pass over a 395M-parameter bidirectional encoder, removing the dependence on output length and preventing hallucinated values by construction.

\paragraph{Grammar-constrained and structured decoding.}
Constrained decoding engines enforce JSON schemas or context-free grammars during generation using finite-state or pushdown automata, including Outlines \citep{willard2023outlines}, SynCode \citep{ugare2025syncode}, SGLang's compressed FSMs \citep{zheng2024sglang}, and XGrammar \citep{dong2025xgrammar}, benchmarked systematically in JSONSchemaBench \citep{geng2025jsonschemabench}. While grammar masks eliminate syntactic errors and can jump over deterministic boilerplate tokens, emitting argument values still requires sequential forward passes and does not prevent semantically ungrounded values. \textsc{SpanCall} enforces schema validity structurally---via deterministic type pre-filtering, exclusivity-constrained DFS, and typed casting---without autoregressive decoding.

\paragraph{Schema-guided slot filling, dialogue state tracking, and span extraction.}
Filling arguments against unseen natural-language schemas is closely related to zero-shot dialogue state tracking (DST), pioneered by the Schema-Guided Dialogue (SGD) benchmark \citep{rastogi2020sgd}, transferable copy-based trackers such as TRADE \citep{wu2019trade}, and TripPy's triple-copy strategy over user utterances, system turns, and prior state \citep{heck2020trippy}. In parallel, bidirectional encoders \citep{devlin2019bert,warner2024modernbert} with boundary-factorized or anchor-conditioned pointer heads---from GlobalPointer \citep{su2022globalpointer} to zero-shot extractors such as GLiNER \citep{zaratiana2024gliner} and guideline-conditioned LLMs such as GoLLIE \citep{sainz2024gollie}---provide fast parallel extraction over open label sets and are the direct ancestors of $H_3$. However, classical DST and NER models assume flat string slots and independent per-slot predictions: they copy verbatim substrings rather than canonicalise booleans, enums, or dates; they lack nested object handling and multi-tool disambiguation; and they do not enforce mutual exclusion between same-type slots. Our canonical context pool $\Omega$, object-leaf decomposition, and constrained joint DFS decoder (\S\ref{sec:method}) supply these missing pieces.

\paragraph{Model routing, cascades, and selective abstention.}
Accelerating LLMs while preserving peak capability has been studied via speculative decoding inside a causal model \citep{leviathan2023speculative} and via query routing or cascades that pair cheaper and stronger LLMs, including FrugalGPT \citep{chen2024frugalgpt}, Hybrid LLM \citep{ding2024hybrid}, and RouteLLM \citep{ong2025routellm}, alongside selective prediction under domain shift \citep{kamath2020selective}. Rather than routing between smaller and larger generative LLMs, our Router pairs a non-autoregressive extractive fast path with an LLM slow path, using joint log-margin, schema validation, and (optionally) a post-$H_1$ schema-type gate for complex tools, invoking the LLM on only 17.6\% (abstention-gated) or 34.3\% (schema-gated) of turns.
